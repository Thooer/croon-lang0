W0、S 与 Library 使用显式快照。S 产生候选，W0 先比较；基准未变时采用同一个 Bundle，不产生一项复制工作区的执行。

预期的 Interface、请求与结束值由 `crates/lang0/cpython/run_delegate.py` 在 CPython 3.12 上独立求出并核对；Kernel 与 Lang0 是被测实现，模型与文件执行按规格给结果。

## 场景
