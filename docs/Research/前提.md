# 前提的证据

这里保留直接影响 Lang0 Surface 和求值实现的研究线索。全部待核验：名称与数据来自网页端 LLM 的搜索报告，尚未对照原文，只作线索。

## 语法与格式

研究观察：没见过的语法容易被模型照相似语法猜测；借用熟悉语言的写法通常更可靠；严格格式约束会挤占推理；先自由生成、再由构造检查报出具体违反规则，通常比全程约束更适合复杂程序。

推断：Lang0 借用 Python 的 Surface，不自造关键字；构造时检查兜底；错误说出违反的规则和替代写法；程序逻辑不依赖约束解码。

## 截断、续写与恢复

研究观察：模型经常不标记截断；缺少锚点时恢复可能建立在虚构状态上；中断会降低多轮任务质量；续写需要框架明确提供状态锚点和截断类别。

推断：Lang0 只在 Atom 之间介入，模型调用中途不注入新内容；恢复从 Journal 的已记录结果重放，不从模型自报状态恢复。

## 反馈与修正

研究观察：失败调用的表面形式会被模型模仿；追加反馈可能覆盖好结果；就地编辑和明确方向可能比不断追加更有效。

推断：这些影响 Lang0 的错误表示和失败传播，但具体反馈策略属于 App 的认知模式，不冻结在 Language 语义里。
